# Coffee Orders Data Analysis with PowerPivot in Excel

## 📌 Project Overview
This project showcases a complete **data analysis workflow** using **Excel PowerPivot**.  
The dataset is composed of three linked tables — **Orders**, **Customers**, and **Products** — representing a coffee sales business.  
The analysis includes data cleaning, transformation, modeling, and insights generation.

---

## 📂 Datasets
- **Orders** – Sales transactions including order date, quantity, price, and product IDs.
- **Customers** – Customer demographics such as location, loyalty status, and join date.
- **Products** – Product details including category, size, and unit price.

---

## 🔧 Data Preparation & Cleaning
Performed using **Power Query**:
- Removed duplicates and blank values.
- Standardized column names and formats.
- Corrected inconsistent data entries.
- Merged and related tables using appropriate keys.

---

## 📊 Data Modeling
Using **PowerPivot**:
- Established relationships between `Orders`, `Customers`, and `Products`.
- Created **new calculated columns** using complex Excel formulas (e.g., profit per unit, category classification).
- Added **measures** using DAX for KPIs such as:
  - Returning customers
  - Profits by returning customers
  - Profit Margin

---

## 📈 Analysis & Insights
The analysis explored:
- Sales trends over time.
- Top-performing products and categories.
- Customer loyalty .
- Profitability by product.

---
